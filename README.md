# YouTube Translator Extension

A lightweight browser extension that translates YouTube subtitles instantly. Just click on any word in the YouTube closed captions (CC), and it will pop up the English meaning right there on the video!

## How to Install (Manual Installation)

Since this extension is open-source and not currently on the Chrome Web Store, you can install it manually in just a few seconds using Developer Mode:

### Step 1: Download the files
1. Click the green **`<> Code`** button at the top of this repository.
2. Select **Download ZIP**.
3. Extract (unzip) the downloaded folder to a location on your computer.

### Step 2: Add it to your browser
*(These steps work for Google Chrome, Brave, and Edge)*
1. Open your browser and type `chrome://extensions/` into the URL address bar.
2. In the top-right corner, toggle the switch to turn on **Developer mode**.
3. In the top-left corner, click the **Load unpacked** button.
4. Select the folder you just unzipped in Step 1.

The extension is now installed and active!

## How to Use
1. Go to any YouTube video and turn on the Closed Captions (CC).
2. Click on any word in the subtitles that you don't understand.
3. A small popup will appear showing the translation.
